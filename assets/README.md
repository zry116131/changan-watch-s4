# 图标素材

`univ-2022-anime-icon-round.png` 为 AI 生成插画，`watch/src/common/logo.png` 是其 192 × 192 启动图标版本。

设计方向：2022 款第一代长安 UNI-V，银灰色、完整侧面朝右，保留修长四门溜背比例；日系赛车动画风格、青蓝破风线条、深色背景、圆形透明四角。没有将插画作为车辆实拍或官方宣传图展示。

车型比例参考：[长安第一代 UNI-V 官方图片](https://www.changan.com.cn/3Dhall/UNI-V/Img/bg_7.jpg)。仓库不包含该参考图片副本。
