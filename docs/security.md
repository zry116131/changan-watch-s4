# 凭据与公开发布

## 数据边界

HA 长期令牌拥有创建账户的权限，不能因网关只读就认为令牌本身权限受限。仅网关保存 HA Token；代码只请求 `/api/states/<entity_id>`，没有代理任意 HA 路径或执行车辆指令的接口。

手表使用独立随机读取密钥。它可从自行构建的 RPK 中被提取，应当按可读取车况的凭据保管；若泄露，更新网关配置和手表连接配置中的密钥并重新安装。HA Token 泄露时还需在 HA 撤销并重新生成。

## 本次公开内容

- 快应用、网关、配置生成器、测试和适配文档。
- 无配置、无真实数据的公开 RPK，以及 SHA-256 校验文件。
- AI 生成的圆形启动图标；不附带参考官网图片副本。

不发布本地配置、已部署私有 RPK、签名私钥、设备序列号、实体 ID、私有地址、安装截图、原始设备日志或 HA 响应。

## 后续发布检查

1. 使用独立、干净的工作副本，`connection.js` 只含空 `baseUrl` 和 `key`。
2. 检查 Git 暂存区，确保没有 `.local/`、`sign/`、`node_modules/` 或私有安装包。
3. 执行网关测试及 `npm ci`、`npm run build`。
4. 解包检查 RPK 全部条目，扫描地址、令牌和私钥；不要仅搜索压缩文件原始字节。
5. 发布无配置包与校验值，明确记录构建验证和实机验证的不同范围。

问题反馈请仅提供脱敏的错误码、型号与版本，不要提供令牌、读取密钥或完整配置。
